# Чат-квест: Не попадись

Интерактивная обучающая игра в формате чата: учит распознавать мошенников и фишинг.
Один файл `index.html`, без зависимостей и сборки.

## Как запустить локально

Открой `index.html` в браузере.

## Публикация на GitHub Pages

1. Создай репозиторий на github.com и загрузи в него все файлы из этой папки.
2. Открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
4. Через 1–2 минуты сайт появится по адресу `https://ТВОЙ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`.
